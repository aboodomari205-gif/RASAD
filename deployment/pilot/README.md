# Authentic static pilot

This bounded packet was exported from the existing read-only indexed NASA FIRMS archive, generation `86f1f872f7366fe4`, not generated by a model. It contains 6,876 original records in Mato Grosso, Brazil, during August 2024. August 24 contains 141 records from both MODIS and VIIRS.

`manifest.json` gives the scope, size and SHA-256 of `evidence.json`. Both the hosted build and browser verify the checksum. The packet is 957,684 bytes; shared datasets and source deliveries are stored once.

Each compact observation array contains, in order: original observation ID, longitude, latitude, UTC timestamp, dataset index, delivery index, native confidence, reported FRP (MW or null), original day/night, source row number, and opaque original row version. Dataset descriptors preserve exact platform/product/processing strata and unresolved lineage flags. Delivery descriptors preserve original source archive/member names and SHA-256. `shared/pilotPacket.js` expands these records without changing coordinates or inventing values.

The existing fitted 60-tree FRP model, actual evaluation and held-out examples accompany the data. They estimate FRP conditional on delivered detections; they never produce hotspot positions. This is not sensor calibration or complete/live Brazil coverage. Missing counterparts and dates have unknown observation opportunity.

To regenerate, run `node deployment/cloudflare/export-pilot.mjs` locally with the original archive available. Hosted builds consume this reviewed packet and do not need the private archive. Tests independently compare the packet with the original indexed records and source-aware overlap computations.
