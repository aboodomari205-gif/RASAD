# Reviewed public archive snapshot

These JSON files are intentionally publishable Ajloun and Northern Jordan derivatives of the existing activated NASA FIRMS generation. `index.json` pins every file hash and source revision. Original record IDs/properties, source identity and unknown-coverage limitations are preserved.

Include this directory in the future GitHub commit. Do not include local SQLite, input ZIP/CSV deliveries, environment files or checkpoints. Cloudflare builds consume this directory without a backend or source archives. Refresh locally only after an authorized archive activation using `npm run prepare:data`, then rerun production checks. Unlisted, orphaned, modified or mixed-revision assets fail validation.
