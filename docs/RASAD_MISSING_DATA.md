Pilot: Mato Grosso, Brazil, bounding box **west -57, south -14, east -55, north -12**, EPSG:4326. First environmental comparison: **2024-08-01–2024-08-31 UTC**; current detection demonstration **2026-11-08–2026-11-14 UTC**, clearly archived rather than live. Broader history is available separately for South America. Do not download continent-wide raster histories.

Download sizes are **not verified**; no estimates are invented. Check provider subset size before download. Earthdata pages return HTTP 403 to this environment; product links are retained, not described as successful downloads. CDS and CHIRPS documentation were readable. No environmental rasters were discovered locally. `scripts/import-environment.mjs` accepts provenance-bearing extracted CSV/JSON point indicators; native raster conversion/QA is not implemented without GDAL/product data. Keep original HDF/GeoTIFF/NetCDF alongside extracted values.

Calibration also requires full MOD14/MYD14 C6.1 masks plus matching MOD03/MYD03 and cloud/valid-pixel QA; VNP14IMG/VJ114IMG/VJ214IMG C2 full masks plus matching IMG geolocation and cloud QA for **every** intersecting overpass, including no-fire overpasses. See SOUTH_AMERICA_ACQUISITION_MANIFEST.json. Request source clarification for NOAA20/21 files claiming Standard processing and early acquisition dates. Current CSV-only pairs cannot create valid negative examples or exposure-normalized training labels.

User steps: sign in to the official provider locally, request only the stated bbox and period, preserve original metadata and checksums in the destinations above, and run the appropriate importer. Never send passwords or tokens through chat. No optional missing raster blocks the observed-detection workflows.
